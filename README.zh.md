# Team Ajan

## 用途

让你的工作(代码、工程计算、建筑项目、产品/界面设计、作业、研究、文章、计划)不是由一双眼睛审查,而是由互相监督的多个独立"团队"审查;如果你愿意,还可以让它们一直修改到没有错误为止。这是一个 Claude Code 插件包。其中有两类文件:**智能体**(说明一个团队如何工作的指令)和**技能**(说明 Claude 如何管理各团队的指令)。

## 安装

1. 如果你拿到的是压缩文件(zip),请先解压到一个文件夹。
2. 双击 `kur.cmd` 文件。确认屏幕上出现"Kuruldu"字样。
3. 关闭 Claude 并重新打开。

`kur.cmd` 只把智能体文件和三个技能文件夹复制到 Claude 的用户文件夹(`%USERPROFILE%\.claude`);同名的旧文件会被覆盖,因此不要在这三个文件夹中以这些名称放置你自己的文件。它会在屏幕上显示目标文件夹。有新版本时,重新运行同一个文件即可。其他安装方式见最下方。

## 安装后的第一句话

在要审查的文件所在的文件夹中打开 Claude,输入以下任意一句。句子中必须出现**"团队"**一词;否则团队不会启动。

| 你想要什么 | 要输入的句子 |
|---|---|
| 只审查,不要动我的文件 | `让团队审查 rapor.md,不要改动` |
| 审查并修改 | `让团队修改 hesap.md,直到没有错误` |
| 专注于一个问题 | `团队只看这个:这个测试为什么偶尔失败?` |
| 单个团队的意见 | `红队来攻击这份作业` · `用黄队的眼光看看` · `青绿队看看有没有浪费` |
| 把我手上的笔记也考虑进去 | `把这个作为笔记交给团队:…` |
| 进行到哪里了 | `团队现在什么情况?` |
| 从中断处继续 · 停止 | `团队继续` · `让团队停下` |

技能触发词是用土耳其语编写的;含有"takım"/"takımlar"(团队)一词的请求能可靠触发;其他语言的请求可能有效,但未经测试。

Claude 会先给出简短概要(它理解了什么、做了哪些假设、多少个团队最多运行多少轮),然后开始。工作期间它可能会请求写文件和运行命令的权限;会请求多少次尚未测量。对写入 `takim` 文件夹的权限可以回答"是";如果对某个命令权限没有把握,请回答"否",该项检验会被报告为"未能查看"。

## 你的文件会怎样

- **如果你说"审查",你的文件不会改变。** 团队被告知只在自己的 `takim` 文件夹中写报告和记录("仅审查");但仍会在 `takim\yedek\` 文件夹中保存一份你文件的副本。
- **如果你说"修改",** Claude 会先把你文件的副本保存到 `takim\yedek\` 文件夹,并告诉你"你的文件将被修改,备份在这里"。只有蓝队会写入你的文件。
- 如果你的请求不明确,Claude 不会动你的文件。
- 团队能否读取 Word 或 PDF 文件尚未验证;Claude 会在开始时说明这一点,并在转换为文本的副本上工作。

## 什么时候结束

如果你说"审查",一轮审查后即结束:Claude 说明发现的问题,并询问是否要修改。如果你说"修改",则在发现的错误已被修改、修改结果经过重新检验、且所有未完成事项都写明了如何收尾时结束。也可能在结束前停止(例如达到最大轮数即"轮数上限"时,或者出现需要你做决定的事情时);停止时 Claude 会说明原因并询问你。停止情形的列表在规则第 8 节。

一轮需要多长时间尚未测量;团队越多,时间和用量越大。

## 团队

| 团队 | 智能体 | 做什么 |
|---|---|---|
| 🔵 蓝队 | `mavi-yazar` | 撰写作品,把每一条异议都落实到一个结论 |
| 🔴 红队 | `kirmizi-saldirgan` | 试图推翻作品的论断 |
| 🩷 粉队 | `pembe-denetci` | 审核发现,结清计数 |
| 🟣 紫队 | `mor-sorgucu` | 检查理解是否正确,提出难题,追查原因 |
| 🟢 绿队 | `yesil-gercek` | 用一手来源核实外部信息,做前期调研 |
| 🟠 橙队 | `turuncu-deneyci` | 亲手运行,重新计算 |
| 🩶 灰队 | `gri-sadelestirici` | 追问"真的需要吗",守住重点 |
| ⚫ 黑队 | `siyah-hafiza` | 捕捉被遗忘的和再次被破坏的;是关卡 |
| ⚪ 白队 | `beyaz-kayitci` | 核实已完成的事,记录无人认领的工作和痕迹 |
| 🟡 黄队 | `sari-kullanici` | 以作品使用者的眼光试用 |
| 🩵 青绿队 | `turkuaz-verimlilik` | 找出 token、读取和调用的浪费,并降到最低(添加到规模中) |

"作品"指被审查的文件或工作。Claude 的界面只为团队识别八种颜色;因此灰队显示为青色,黑队和白队没有颜色。请按名称识别团队。

## 规模与模式

**规模**指运行多少个团队。如果你不指定,Claude 会根据工作大小选择并告知你。

| 规模 | 团队 | 轮数上限 | 适用于 |
|---|---|---|---|
| 快速 | 蓝、红、粉 | 2 | 小工作、单个文件、快速检查 |
| 标准 | + 绿、灰、橙 | 5 | 大多数工作 |
| 完整 | + 紫、黄、黑、白 | 10 | 关键、长期使用或撤回代价高的工作 |

可以向规模中逐个添加团队("快速规模,也加上黄队");对于作业和文章,Claude 会自动添加黄队,对于需要运行的工作会自动添加橙队,并告知你。轮数上限是未经测试的初始值;想修改,告诉 Claude 即可。

**模式**指看什么:**广泛**(整个工作)或**聚焦**(单个问题)。如果你只问一个问题,Claude 会选择聚焦模式。

## 结果在哪里

- 结果由 Claude 在对话中告诉你:最上面一句话,下面是简短概要;哪些是**有证据的**、哪些是*推测*会分开说明;如果有问题,放在最下面。
- 你工作的文件夹中会创建一个 `takim` 文件夹。这是团队自己的记录;你不需要阅读。你文件的原始版本也在这个文件夹中(`takim\yedek\`);如果你对修改满意,工作结束后可以删除。
- 要给团队提供笔记或报告,可以把文件放到 `takim\gelen\` 文件夹中。
- 如果在同一文件夹中开始新工作,旧记录不会被删除,而是被移到 `takim\arsiv\` 下。

规则全文:`skills/takim-dongu/sablonlar/kurallar.md`。

## 卸载

- 如果用 `kur.cmd` 安装:双击 `kaldir.cmd` 文件。它只删除本包的智能体文件和三个技能文件夹;不会动你项目中的 `takim` 文件夹。如果有删不掉的文件,会在屏幕上提示。
- 如果作为插件安装:在 Claude Code 中输入 `/plugin`,在打开的窗口中移除插件(此步骤未经验证)。
- 如果复制到了单个项目:从该项目的 `.claude` 文件夹中删除你复制的文件。

## 其他安装方式(高级)

只使用其中一种。如果在使用 `kur.cmd` 的同时也使用插件方式,团队会在列表中出现两次。

**作为插件。** 在下方写有 `<takim-ajan klasörünün yolu>` 的地方填入此文件夹在你电脑上的完整路径。在 Claude Code 中:

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

第二条命令不会自动完成安装:它会打开一个窗口,你在其中选择用户范围。Windows 路径在此命令中能否被正确读取尚未验证。作为插件安装后,智能体和技能名称前会加上 `takim-ajan:`。

**安装到单个项目。** 把 `agents` 文件夹中的内容复制到项目的 `.claude\agents` 文件夹,把 `skills` 文件夹中的三个文件夹复制到项目的 `.claude\skills` 文件夹。三个技能文件夹必须一起复制。
