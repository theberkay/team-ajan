# Team Ajan

🌐 [Türkçe](README.md) · [English](README.en.md) · [All languages](LANGUAGES.md)

## 它能做什么

它让你的一项工作（代码、工程计算、建筑项目、产品／界面设计、作业、研究、文章、计划）不是由一双眼睛审查，而是由相互检查的独立"团队"审查；如果你愿意，它会让团队一直修改，直到没有错误为止。它是 Claude Code 的一个插件包。其中有两类文件：**智能体**（agent，说明一个团队如何工作的指令）和 **技能**（skill，说明 Claude 如何管理各团队的指令）。

领域指南（`skills/takim-dongu/sablonlar/alanlar.md`）告诉团队在以下领域应关注什么：代码、工程、机械、机电一体化、电气、重工业、建筑、设计与造型、知识讲解与作业、演示、研究、文档、医学、法律、政治、历史、音乐。在医学和法律领域，团队不作诊断、不给治疗方案，也不提供法律意见；它们只审查文本及其来源，结果会附上"应咨询专业人士"的说明。

## 安装

1. 如果你拿到的是压缩文件（zip），请先解压到一个文件夹。
2. 双击 `kur.cmd`。屏幕上会显示"Kuruldu"（已安装）。
3. 关闭 Claude 并重新打开。

`kur.cmd` 只会把智能体文件和三个技能文件夹复制到 Claude 的用户文件夹（`%USERPROFILE%\.claude`）；它会覆盖同名的旧文件，所以不要在这三个文件夹里或用这些名称放你自己的文件。它会在屏幕上显示目标文件夹。有新版本时，只需再次运行同一个文件。其他安装方式在最下方。

## 安装后的第一句话

在待审查文件所在的文件夹中打开 Claude，输入下列句子之一。句子中必须包含 **"takım"**（团队）一词；否则团队不会启动。

| 你想要什么 | 要输入的句子 |
|---|---|
| 只审查，不要动我的文件 | `让团队审查 rapor.md，不要改动它` |
| 审查并修改 | `让团队修改 hesap.md，直到没有错误` |
| 专注于一个问题 | `团队只看这个：这个测试为什么时不时失败？` |
| 单个团队的意见 | `红队，攻击这份作业` · `用黄队的眼光看看` · `青绿队，找找浪费` |
| 也考虑我的笔记 | `把这个作为笔记交给团队：…` |
| 进展到哪里了 | `团队进展如何？` |
| 从中断处继续 · 停止 | `团队继续` · `停止团队` |

技能触发词是用土耳其语写的；包含"takım"／"takımlar"的请求能可靠触发；用其他语言提出的请求也许可行，但未经测试。

Claude 会先给出简短摘要（它理解了什么、假设了什么、几个团队最多工作几轮），然后开始。工作中它可能请求写入文件和运行命令的权限；会请求多少次尚未测量。对写入 `takim` 文件夹的权限可以回答"是"；如果对某个命令权限没有把握，就回答"否"，该项检查会被报告为"无法检查"。

## 你的文件会怎样

- **如果你说"审查"，你的文件不会改变。** 团队被告知只把报告和记录写入它们自己的 `takim` 文件夹（"仅审查"）；不过你的文件仍会被复制一份到 `takim\yedek\` 文件夹。
- **如果你说"修改"，** Claude 会先把你的文件复制到 `takim\yedek\` 文件夹，并告诉你"你的文件将被修改，备份在这里"。只有蓝队会写入你的文件。
- 如果你的请求不明确，Claude 不会动你的文件。
- 团队能否读取 Word 或 PDF 文件尚未验证；Claude 会在开始时说明这一点，并在转换成文本的副本上工作。

## 何时结束

如果你说的是"审查"，在一轮审查后结束：Claude 说明发现了什么，并询问是否修改。如果你说的是"修改"，在发现的错误已修正、修正已重新检验、且每件未完成事项如何收尾都已写明时结束。它也可能在完成前停下（例如达到最大轮数即"轮数上限"时，或出现需要你决定的事情时）；停下时，Claude 会说明原因并询问。停止情形的清单在规则第 8 节。

一轮需要多长时间尚未测量；团队越多，时间和用量越大。

## 团队

| 团队 | 智能体 | 做什么 |
|---|---|---|
| 🔵 蓝队 | `mavi-yazar` | 撰写成果，把每条异议落实到结论 |
| 🔴 红队 | `kirmizi-saldirgan` | 设法推翻成果中的论断 |
| 🩷 粉队 | `pembe-denetci` | 审核发现，完成计数 |
| 🟣 紫队 | `mor-sorgucu` | 检验理解，提出难题，追查原因 |
| 🟢 绿队 | `yesil-gercek` | 从一手来源核实外部信息，做前期调研 |
| 🟠 橙队 | `turuncu-deneyci` | 亲手运行，重新计算 |
| 🩶 灰队 | `gri-sadelestirici` | 追问"真的有必要吗"，保持聚焦 |
| ⚫ 黑队 | `siyah-hafiza` | 抓住被遗忘的和再次出错的；它是关卡 |
| ⚪ 白队 | `beyaz-kayitci` | 核实已完成的工作，记录无人负责的工作和轨迹 |
| 🟡 黄队 | `sari-kullanici` | 以使用者的眼光试用成果 |
| 🩵 青绿队 | `turkuaz-verimlilik` | 找出 token、读取和调用上的浪费并降到最低（可加入某个规模） |

"成果"指被审查的你的文件或工作。Claude 的界面只能为团队识别八种颜色；因此灰队显示为青色，黑队和白队没有颜色。请按名称识别团队。

## 规模与模式

**规模**是指有几个团队工作。如果你不指定，Claude 会根据工作量选择并告诉你。

| 规模 | 团队 | 轮数上限 | 适用于 |
|---|---|---|---|
| 快速 | 蓝、红、粉 | 2 | 小任务、单个文件、快速检查 |
| 常规 | + 绿、灰、橙 | 5 | 大多数工作 |
| 完整 | + 紫、黄、黑、白 | 10 | 关键的、长期使用的或撤销代价高的工作 |

可以逐个向某个规模添加团队（"快速规模，再加上黄队"）；对作业和文章，Claude 会自行加入黄队，对需要运行的工作加入橙队，并会说明。轮数上限是未经测试的初始值；想改只需说一声。

**模式**是指看什么：**全面**（整个工作）或 **聚焦**（单个问题）。如果你只问一个问题，Claude 会选择聚焦模式。

## 结果在哪里

- Claude 在对话中告诉你结果：最上面一句话，下面是简短摘要；哪些是**已证实的**、哪些是*推测*，会分开说明；如有问题，放在最下面。
- 在你工作的文件夹中会创建一个 `takim` 文件夹。这是团队自己的记录；你无需阅读。你文件的最初版本也在这个文件夹里（`takim\yedek\`）；如果你对修改满意，工作结束后可以删除它。
- 要给团队提供笔记或报告，可以把文件放入 `takim\gelen\` 文件夹。
- 如果在同一文件夹中开始新工作，旧记录不会被删除；它们会被移到 `takim\arsiv\` 下。

规则全文：`skills/takim-dongu/sablonlar/kurallar.md`。

## 卸载

- 如果用 `kur.cmd` 安装：双击 `kaldir.cmd`。它只删除本包的智能体文件和三个技能文件夹；不会动你项目中的 `takim` 文件夹。如有未能删除的文件残留，它会在屏幕上说明。
- 如果作为插件安装：在 Claude Code 中输入 `/plugin`，在打开的窗口中移除插件（此步骤未经验证）。
- 如果复制到了单个项目：从该项目的 `.claude` 文件夹中删除你复制的文件。

## 其他安装方式（进阶）

只使用其中一种。如果在 `kur.cmd` 之外还使用插件方式，团队会在列表中出现两次。

**作为插件。** 把下面写着 `<takim-ajan klasörünün yolu>` 的地方换成此文件夹在你电脑上的完整路径。在 Claude Code 中：

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

第二条命令不会自行完成安装：它会打开一个窗口；你在那里选择用户范围。此命令能否正确读取 Windows 路径尚未验证。作为插件安装后，智能体和技能名称前会加上 `takim-ajan:`。

**装到单个项目。** 把 `agents` 文件夹里的内容复制到项目的 `.claude\agents` 文件夹，把 `skills` 文件夹中的三个文件夹复制到项目的 `.claude\skills` 文件夹。三个技能文件夹必须一起复制。
