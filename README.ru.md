# Team Ajan

## Для чего это нужно

Ваша работа (код, инженерный расчёт, архитектурный проект, дизайн продукта / интерфейса, домашнее задание, исследование, текст, план) проверяется не одним взглядом, а отдельными «командами», которые контролируют друг друга; при желании они будут исправлять её, пока не останется ошибок. Это пакет-плагин для Claude Code. В нём два вида файлов: **агенты** (инструкции о том, как работает команда) и **навыки** (инструкции о том, как Claude управляет командами).

## Установка

1. Если вы получили пакет в виде архива (zip), сначала распакуйте его в папку.
2. Дважды щёлкните файл `kur.cmd`. Убедитесь, что на экране появилась надпись «Kuruldu».
3. Закройте Claude и откройте снова.

`kur.cmd` копирует только файлы агентов и три папки навыков в пользовательскую папку Claude (`%USERPROFILE%\.claude`); старые файлы с теми же именами перезаписываются, поэтому не кладите в эти три папки собственные файлы с такими именами. Целевая папка показывается на экране. Когда выйдет новая версия, достаточно снова запустить тот же файл. Другие способы установки — в самом конце.

## Первая фраза после установки

Откройте Claude в папке, где лежит файл для проверки, и напишите одну из этих фраз. В фразе должно быть слово **«команда»**; без него команды не включатся.

| Чего вы хотите | Что написать |
|---|---|
| Только проверить, не трогая мой файл | `пусть команды проверят rapor.md, ничего не меняя` |
| Проверить и исправить | `пусть команды исправляют hesap.md, пока не останется ошибок` |
| Сосредоточиться на одном вопросе | `пусть команды посмотрят только на это: почему этот тест иногда падает?` |
| Мнение одной команды | `красная команда, атакуй это задание` · `посмотри глазами жёлтой команды` · `бирюзовая команда, поищи лишние затраты` |
| Учесть и мою заметку | `передай это командам как заметку: …` |
| Где они остановились | `как дела у команд?` |
| Продолжить с того места · остановиться | `пусть команды продолжают` · `останови команды` |

Триггеры навыков написаны на турецком языке; запросы со словом «takım» / «takımlar» (команда / команды) срабатывают надёжно; запросы на других языках могут работать, но не проверялись.

Сначала Claude даёт краткую сводку (что он понял, что предположил, сколько команд будет работать и не более скольких раундов) и начинает. Во время работы он может запрашивать разрешение на запись файлов и запуск команд; сколько раз он будет спрашивать, пока не измерено. На разрешения записи в папку `takim` можно отвечать «да»; если вы не уверены в разрешении на команду, ответьте «нет» — эта проверка будет отмечена в отчёте как «не удалось проверить».

## Что будет с вашим файлом

- **Если вы скажете «проверить», ваш файл не изменится.** Командам велено писать отчёты и журналы только в свою папку `takim` («только проверка»); копия вашего файла всё равно сохраняется в папку `takim\yedek\`.
- **Если вы скажете «исправить»,** Claude сначала сохранит копию вашего файла в папку `takim\yedek\` и скажет вам: «ваш файл будет изменён, резервная копия здесь». В ваш файл пишет только Синяя команда.
- Если ваш запрос неясен, Claude не трогает ваш файл.
- То, что команды могут читать файлы Word или PDF, не проверено; Claude сообщает об этом в начале и работает с копией, преобразованной в текст.

## Когда это заканчивается

Если вы сказали «проверить», всё заканчивается после одного раунда проверки: Claude рассказывает, что нашёл, и спрашивает, исправлять ли. Если вы сказали «исправить», всё заканчивается, когда найденные ошибки исправлены, исправление заново проверено и для всего незавершённого записано, как оно будет закрыто. Работа может остановиться и раньше (например, при достижении максимального числа раундов — «потолка раундов» — или когда появится что-то, что должны решить вы); при остановке Claude объясняет причину и спрашивает. Список случаев остановки — в разделе 8 правил.

Сколько длится один раунд, не измерено; чем больше команд, тем больше время и расход.

## Команды

| Команда | Агент | Что делает |
|---|---|---|
| 🔵 Синяя | `mavi-yazar` | Пишет произведение, доводит каждое возражение до результата |
| 🔴 Красная | `kirmizi-saldirgan` | Пытается опровергнуть утверждения произведения |
| 🩷 Розовая | `pembe-denetci` | Проверяет находки, закрывает подсчёт |
| 🟣 Фиолетовая | `mor-sorgucu` | Проверяет понимание, задаёт трудные вопросы, расследует причину |
| 🟢 Зелёная | `yesil-gercek` | Проверяет внешние сведения по первоисточнику, проводит предварительное исследование |
| 🟠 Оранжевая | `turuncu-deneyci` | Запускает своими руками, пересчитывает |
| 🩶 Серая | `gri-sadelestirici` | Спрашивает «действительно ли это нужно», сохраняет фокус |
| ⚫ Чёрная | `siyah-hafiza` | Ловит забытое и снова сломанное; является шлюзом |
| ⚪ Белая | `beyaz-kayitci` | Проверяет сделанное, записывает бесхозную работу и след |
| 🟡 Жёлтая | `sari-kullanici` | Пробует произведение глазами того, кто будет им пользоваться |
| 🩵 Бирюзовая | `turkuaz-verimlilik` | Находит перерасход токенов, чтений и вызовов, сводит его к минимуму (добавляется к составу) |

«Произведение» — это проверяемый файл или ваша работа. Экран Claude распознаёт для команд только восемь цветов; поэтому Серая выглядит голубой, а у Чёрной и Белой цвета нет. Узнавайте команду по имени.

## Составы и режимы

**Состав** — это сколько команд будет работать. Если вы не скажете, Claude выберет по размеру работы и сообщит.

| Состав | Команды | Потолок раундов | Для чего |
|---|---|---|---|
| Быстрый | Синяя, Красная, Розовая | 2 | Маленькая работа, один файл, быстрая проверка |
| Обычный | + Зелёная, Серая, Оранжевая | 5 | Большинство работ |
| Полный | + Фиолетовая, Жёлтая, Чёрная, Белая | 10 | Критичная, долгоживущая или дорогая для отката работа |

К составу можно добавлять команды по одной («быстрый состав, добавь ещё жёлтую команду»); для заданий и текстов Claude сам добавляет Жёлтую, для работы, требующей запуска, — Оранжевую, и сообщает об этом. Потолки раундов — непроверенные начальные значения; чтобы изменить, достаточно сказать.

**Режим** — это то, на что смотреть: **широкий** (вся работа) или **фокус** (один вопрос). Если вы задаёте один вопрос, Claude выбирает режим фокуса.

## Где результат

- Результат Claude рассказывает вам в чате: вверху одно предложение, под ним краткая сводка; что **доказано**, а что — *предположение*, говорится отдельно; если есть вопрос, он стоит в самом низу.
- В вашей рабочей папке создаётся папка `takim`. Это собственный журнал команд; читать его не нужно. Исходная версия вашего файла тоже находится в этой папке (`takim\yedek\`); если исправления вас устраивают, после завершения работы её можно удалить.
- Чтобы передать командам заметку или отчёт, можно положить файл в папку `takim\gelen\`.
- Если вы начнёте новую работу в той же папке, старые записи не удаляются, а переносятся в `takim\arsiv\`.

Полный текст правил: `skills/takim-dongu/sablonlar/kurallar.md`.

## Удаление

- Если вы устанавливали через `kur.cmd`: дважды щёлкните файл `kaldir.cmd`. Он удаляет только файлы агентов пакета и три папки навыков; папки `takim` в ваших проектах не трогает. Если какой-то файл удалить не удалось, он сообщит об этом на экране.
- Если вы устанавливали как плагин: в Claude Code введите `/plugin` и удалите плагин в открывшемся окне (этот шаг не проверен).
- Если вы копировали в один проект: удалите скопированные файлы из папки `.claude` этого проекта.

## Другие способы установки (для опытных)

Используйте только один. Если вместе с `kur.cmd` использовать и способ с плагином, команды появятся в списке дважды.

**Как плагин.** Ниже, вместо `<takim-ajan klasörünün yolu>`, подставьте полный путь к этой папке на вашем компьютере. В Claude Code:

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

Вторая команда не завершает установку сама: она открывает окно, где вы выбираете пользовательскую область. Правильно ли эта команда читает путь Windows, не проверено. При установке как плагина к именам агентов и навыков добавляется префикс `takim-ajan:`.

**В один проект.** Скопируйте содержимое папки `agents` в папку проекта `.claude\agents`, а три папки из папки `skills` — в папку проекта `.claude\skills`. Три папки навыков нужно копировать вместе.
