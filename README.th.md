## ใช้ทำอะไร

ให้ "ทีม" หลายทีมที่ตรวจสอบกันเองตรวจงานของคุณ (โค้ด การคำนวณทางวิศวกรรม โครงการสถาปัตยกรรม การออกแบบผลิตภัณฑ์ / ส่วนติดต่อผู้ใช้ การบ้าน งานวิจัย งานเขียน แผนงาน) แทนที่จะดูด้วยสายตาคู่เดียว และหากต้องการ ก็ให้แก้ไขจนไม่เหลือข้อผิดพลาด เป็นชุดปลั๊กอินสำหรับ Claude Code ภายในมีไฟล์สองประเภท: **เอเจนต์** (คำสั่งที่บอกว่าทีมหนึ่งทำงานอย่างไร) และ **สกิล** (คำสั่งที่บอกว่า Claude ควบคุมทีมต่าง ๆ อย่างไร)

## ติดตั้ง

1. หากคุณได้รับชุดนี้เป็นไฟล์บีบอัด (zip) ให้แตกไฟล์ลงในโฟลเดอร์ก่อน
2. ดับเบิลคลิกไฟล์ `kur.cmd` แล้วดูว่าบนหน้าจอขึ้นข้อความ "Kuruldu"
3. ปิด Claude แล้วเปิดใหม่

`kur.cmd` คัดลอกเฉพาะไฟล์เอเจนต์และโฟลเดอร์สกิลสามโฟลเดอร์ไปยังโฟลเดอร์ผู้ใช้ของ Claude (`%USERPROFILE%\.claude`) โดยเขียนทับของเก่าที่ชื่อเดียวกัน ดังนั้นอย่าวางไฟล์ของคุณเองไว้ในสามโฟลเดอร์นั้นด้วยชื่อเหล่านั้น โปรแกรมจะแสดงโฟลเดอร์ปลายทางบนหน้าจอ เมื่อมีรุ่นใหม่ เพียงเรียกไฟล์เดิมอีกครั้งก็พอ วิธีติดตั้งอื่นอยู่ด้านล่างสุด

## ประโยคแรกหลังติดตั้ง

เปิด Claude ในโฟลเดอร์ที่มีไฟล์ที่จะตรวจ แล้วพิมพ์ประโยคใดประโยคหนึ่งต่อไปนี้ ประโยคต้องมีคำว่า **"takım"** (ทีม) หากไม่มี ทีมต่าง ๆ จะไม่เริ่มทำงาน

| คุณต้องการอะไร | ประโยคที่พิมพ์ |
|---|---|
| ให้ตรวจอย่างเดียว ไม่แตะไฟล์ของฉัน | `ให้ทีมตรวจไฟล์ rapor.md โดยไม่ต้องแก้ไข` |
| ให้ตรวจและแก้ไข | `ให้ทีมแก้ไฟล์ hesap.md จนไม่เหลือข้อผิดพลาด` |
| ให้โฟกัสคำถามเดียว | `ให้ทีมดูเฉพาะเรื่องนี้: ทำไมเทสต์นี้ล้มเป็นบางครั้ง?` |
| ความเห็นจากทีมเดียว | `ให้ทีมแดงโจมตีการบ้านนี้` · `มองด้วยสายตาของทีมเหลือง` · `ให้ทีมเทอร์ควอยซ์ดูความสิ้นเปลือง` |
| ให้พิจารณาบันทึกที่ฉันมีด้วย | `ส่งสิ่งนี้ให้ทีมเป็นบันทึก: …` |
| ทำถึงไหนแล้ว | `ทีมต่าง ๆ เป็นอย่างไรบ้าง?` |
| ให้ทำต่อจากที่ค้างไว้ · ให้หยุด | `ให้ทีมทำต่อ` · `หยุดทีม` |

> สิ่งที่สั่งให้สกิลทำงานเขียนไว้เป็นภาษาตุรกี คำขอที่มีคำว่า "takım" / "takımlar" จะสั่งให้ทำงานได้อย่างเชื่อถือได้ คำขอในภาษาอื่นอาจใช้ได้ แต่ยังไม่ได้ทดสอบ

Claude จะสรุปสั้น ๆ ก่อน (เข้าใจว่าอะไร สันนิษฐานอะไร กี่ทีมจะทำงานได้มากสุดกี่รอบ) แล้วจึงเริ่ม ระหว่างทำงาน อาจขออนุญาตเขียนไฟล์และเรียกคำสั่ง ยังไม่ได้วัดว่าจะถามกี่ครั้ง คุณตอบตกลงกับการอนุญาตเขียนในโฟลเดอร์ `takim` ได้ หากไม่แน่ใจเรื่องการอนุญาตคำสั่งใด ให้ตอบไม่ การทดสอบนั้นจะถูกรายงานว่า "ตรวจไม่ได้"

## จะเกิดอะไรกับไฟล์ของคุณ

- **หากคุณบอกให้ "ตรวจ" ไฟล์ของคุณจะไม่เปลี่ยน** ทีมต่าง ๆ ได้รับคำสั่งให้เขียนรายงานและสมุดบันทึกลงในโฟลเดอร์ `takim` ของตนเท่านั้น ("ตรวจอย่างเดียว") แต่ถึงอย่างนั้นก็จะมีการสำรองไฟล์ของคุณไว้ในโฟลเดอร์ `takim\yedek\`
- **หากคุณบอกให้ "แก้ไข"** Claude จะสำรองไฟล์ของคุณไว้ในโฟลเดอร์ `takim\yedek\` ก่อน แล้วบอกคุณว่า "ไฟล์ของคุณจะเปลี่ยน สำเนาอยู่ที่นี่" มีเพียงทีมน้ำเงินที่เขียนลงไฟล์ของคุณ
- หากคำขอของคุณไม่ชัดเจน Claude จะไม่แตะไฟล์ของคุณ
- ยังไม่ได้ยืนยันว่าทีมต่าง ๆ อ่านไฟล์ Word หรือ PDF ได้ Claude จะแจ้งเรื่องนี้ตั้งแต่ต้นและทำงานกับสำเนาที่แปลงเป็นข้อความ

## จะจบเมื่อไร

หากคุณบอกให้ "ตรวจ" จะจบหลังการตรวจหนึ่งรอบ: Claude เล่าสิ่งที่พบและถามว่าจะให้แก้ไขไหม หากคุณบอกให้ "แก้ไข" จะจบเมื่อข้อผิดพลาดที่พบได้รับการแก้ และทดสอบซ้ำแล้วว่าแก้แล้วจริง และเขียนไว้แล้วว่าทุกอย่างที่ค้างจะปิดอย่างไร อาจหยุดก่อนจบได้ด้วย (เช่น เมื่อถึงจำนวนรอบสูงสุดหรือ "เพดานรอบ" หรือเมื่อมีเรื่องที่คุณต้องตัดสินใจ) เมื่อหยุด Claude จะอธิบายเหตุผลและถามคุณ รายการกรณีที่หยุดอยู่ในหมวดที่ 8 ของกฎ

ยังไม่ได้วัดว่าหนึ่งรอบใช้เวลานานเท่าไร ยิ่งมีทีมมาก เวลาและการใช้งานยิ่งเพิ่ม

## ขนาดและโหมด

**ขนาด** คือจำนวนทีมที่จะทำงาน หากคุณไม่ระบุ Claude จะเลือกตามขนาดของงานและแจ้งให้ทราบ

| ขนาด | ทีม | เพดานรอบ | ใช้กับ |
|---|---|---|---|
| เร็ว | น้ำเงิน แดง ชมพู | 2 | งานเล็ก ไฟล์เดียว ตรวจเร็ว |
| ปกติ | + เขียว เทา ส้ม | 5 | งานส่วนใหญ่ |
| เต็ม | + ม่วง เหลือง ดำ ขาว | 10 | งานสำคัญ อายุยาว หรือย้อนกลับได้ยากและแพง |

เพิ่มทีมทีละทีมเข้าไปในขนาดได้ ("ขนาดเร็ว เพิ่มทีมเหลืองด้วย") สำหรับการบ้านและงานเขียน Claude จะเพิ่มทีมเหลืองเอง สำหรับงานที่ต้องเรียกใช้ จะเพิ่มทีมส้มเองและแจ้งให้ทราบ เพดานรอบเป็นค่าเริ่มต้นที่ยังไม่ได้ทดสอบ หากต้องการเปลี่ยน เพียงบอกก็พอ

**โหมด** คือสิ่งที่จะตรวจ: **กว้าง** (ทั้งงาน) หรือ **โฟกัส** (คำถามเดียว) หากคุณถามคำถามเดียว Claude จะเลือกโหมดโฟกัส

## ผลลัพธ์อยู่ที่ไหน

- Claude จะเล่าผลให้คุณในแชต: ด้านบนสุดหนึ่งประโยค ด้านล่างเป็นสรุปสั้น ๆ แยกบอกว่าอะไร **มีหลักฐาน** อะไรเป็น *การคาดเดา* หากมีคำถามจะอยู่ด้านล่างสุด
- จะมีโฟลเดอร์ `takim` เกิดขึ้นในโฟลเดอร์ที่คุณทำงาน นี่คือสมุดบันทึกของทีม คุณไม่จำเป็นต้องอ่าน ไฟล์ฉบับแรกของคุณก็อยู่ในโฟลเดอร์นี้ (`takim\yedek\`) หากพอใจกับการแก้ไข ลบได้หลังงานเสร็จ
- หากต้องการส่งบันทึกหรือรายงานให้ทีม วางไฟล์ไว้ในโฟลเดอร์ `takim\gelen\` ได้
- หากเริ่มงานใหม่ในโฟลเดอร์เดิม บันทึกเก่าจะไม่ถูกลบ แต่จะย้ายไปไว้ใต้ `takim\arsiv\`

ข้อความกฎฉบับเต็ม: `skills/takim-dongu/sablonlar/kurallar.md`

## ถอนการติดตั้ง

- หากติดตั้งด้วย `kur.cmd`: ดับเบิลคลิกไฟล์ `kaldir.cmd` จะลบเฉพาะไฟล์เอเจนต์ของชุดนี้และโฟลเดอร์สกิลสามโฟลเดอร์ ไม่แตะโฟลเดอร์ `takim` ในโปรเจกต์ของคุณ หากมีไฟล์ที่ลบไม่ได้ จะแจ้งบนหน้าจอ
- หากติดตั้งเป็นปลั๊กอิน: พิมพ์ `/plugin` ใน Claude Code แล้วถอนปลั๊กอินจากหน้าต่างที่เปิดขึ้น (ขั้นตอนนี้ยังไม่ได้ยืนยัน)
- หากคัดลอกไว้ในโปรเจกต์เดียว: ลบไฟล์ที่คัดลอกออกจากโฟลเดอร์ `.claude` ของโปรเจกต์นั้น

## วิธีติดตั้งอื่น (ขั้นสูง)

ใช้เพียงวิธีเดียว หากใช้ทั้ง `kur.cmd` และวิธีปลั๊กอิน ทีมต่าง ๆ จะแสดงในรายการสองครั้ง

**เป็นปลั๊กอิน** ด้านล่าง ตรงที่เขียนว่า `<takim-ajan klasörünün yolu>` ให้ใส่พาธเต็มของโฟลเดอร์นี้ในคอมพิวเตอร์ของคุณ ใน Claude Code:

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

คำสั่งที่สองไม่ได้ติดตั้งจนเสร็จเอง: จะเปิดหน้าต่างขึ้นมา ซึ่งคุณเลือกขอบเขตผู้ใช้ที่นั่น ยังไม่ได้ยืนยันว่าคำสั่งนี้อ่านพาธ Windows ได้ถูกต้อง เมื่อติดตั้งเป็นปลั๊กอิน ชื่อเอเจนต์และสกิลจะมี `takim-ajan:` นำหน้า

**ในโปรเจกต์เดียว** คัดลอกสิ่งที่อยู่ในโฟลเดอร์ `agents` ไปยังโฟลเดอร์ `.claude\agents` ของโปรเจกต์ และคัดลอกสามโฟลเดอร์ในโฟลเดอร์ `skills` ไปยังโฟลเดอร์ `.claude\skills` ของโปรเจกต์ ต้องคัดลอกโฟลเดอร์สกิลทั้งสามไปพร้อมกัน
