## આ શું કામ આવે છે

તે તમારા કોઈ કામ (કોડ, એન્જિનિયરિંગ ગણતરી, સ્થાપત્ય પ્રોજેક્ટ, પ્રોડક્ટ / ઇન્ટરફેસ ડિઝાઇન, ગૃહકાર્ય, સંશોધન, લેખન, યોજના)ની તપાસ એક જ નજરથી નહીં, પણ એકબીજાને ચકાસતી અલગ-અલગ "ટીમો" પાસે કરાવે છે; તમે ઇચ્છો તો કોઈ ભૂલ ન રહે ત્યાં સુધી સુધારાવે છે. આ Claude Code માટેનું એક પ્લગઇન પેકેજ છે. તેમાં બે પ્રકારની ફાઇલો છે: **એજન્ટ** (કોઈ ટીમ કેવી રીતે કામ કરશે તે વર્ણવતી સૂચના) અને **કૌશલ્ય** (Claude ટીમોનું સંચાલન કેવી રીતે કરશે તે વર્ણવતી સૂચના).

## ઇન્સ્ટોલ કરો

1. જો તમને પેકેજ સંકુચિત ફાઇલ (zip) તરીકે મળ્યું હોય, તો પહેલાં તેને કોઈ ફોલ્ડરમાં કાઢો.
2. `kur.cmd` ફાઇલ પર ડબલ-ક્લિક કરો. સ્ક્રીન પર "Kuruldu" લખાણ જુઓ.
3. Claude બંધ કરીને ફરી ખોલો.

`kur.cmd` ફક્ત એજન્ટ ફાઇલો અને ત્રણ કૌશલ્ય ફોલ્ડરોને Claudeના વપરાશકર્તા ફોલ્ડર (`%USERPROFILE%\.claude`)માં નકલ કરે છે; તે સમાન નામવાળી જૂની ફાઇલો પર ફરીથી લખે છે, તેથી તે ત્રણ ફોલ્ડરોમાં અથવા તે નામોથી તમારી પોતાની ફાઇલ ન રાખો. તે લક્ષ્ય ફોલ્ડર સ્ક્રીન પર બતાવે છે. નવું સંસ્કરણ આવે ત્યારે એ જ ફાઇલ ફરી ચલાવવી પૂરતી છે. બીજી ઇન્સ્ટોલ પદ્ધતિઓ સૌથી નીચે છે.

## ઇન્સ્ટોલ કર્યા પછીનું તમારું પહેલું વાક્ય

જે ફોલ્ડરમાં તપાસવાની ફાઇલ છે ત્યાં Claude ખોલો અને નીચેનામાંથી કોઈ એક લખો. વાક્યમાં **"ટીમ"** શબ્દ હોવો જોઈએ; ન હોય તો ટીમો સક્રિય થતી નથી.

| તમે શું ઇચ્છો છો | તમે લખશો તે વાક્ય |
|---|---|
| ફક્ત તપાસે, મારી ફાઇલને અડકે નહીં | `rapor.md ફાઇલ ટીમો પાસે તપાસાવો, તેઓ તેને અડકે નહીં` |
| તપાસે અને સુધારે | `ટીમો hesap.md ફાઇલને કોઈ ભૂલ ન રહે ત્યાં સુધી સુધારે` |
| એક જ પ્રશ્ન પર ધ્યાન આપે | `ટીમો ફક્ત આ જુએ: આ ટેસ્ટ ક્યારેક-ક્યારેક કેમ નિષ્ફળ જાય છે?` |
| એક જ ટીમનો અભિપ્રાય | `લાલ ટીમ આ ગૃહકાર્ય પર હુમલો કરે` · `પીળી ટીમની નજરે જુઓ` · `ફિરોઝી ટીમ બગાડ શોધે` |
| મારી નોંધ પણ ધ્યાનમાં લે | `આ ટીમોને નોંધ તરીકે આપો: …` |
| તેઓ ક્યાં અટક્યા છે | `ટીમો કઈ સ્થિતિમાં છે?` |
| જ્યાં અટક્યા ત્યાંથી આગળ વધે · અટકે | `ટીમો ચાલુ રાખે` · `ટીમોને રોકો` |

કૌશલ્યના ટ્રિગર તુર્કી ભાષામાં લખાયેલા છે; "takım" / "takımlar" શબ્દ ધરાવતી વિનંતીઓ વિશ્વસનીય રીતે ટ્રિગર કરે છે; બીજી ભાષાઓની વિનંતીઓ કામ કરી શકે, પણ તેની ચકાસણી થઈ નથી.

Claude પહેલાં ટૂંકો સાર આપે છે (તેણે શું સમજ્યું, શું ધાર્યું, કેટલી ટીમો વધુમાં વધુ કેટલા રાઉન્ડ કામ કરશે) અને શરૂ કરે છે. કામ દરમિયાન તે ફાઇલ લખવા અને આદેશ ચલાવવા પરવાનગી માગી શકે છે; તે કેટલી વાર પૂછશે તે હજી માપવામાં આવ્યું નથી. `takim` ફોલ્ડરમાં લખવાની પરવાનગીઓને તમે હા કહી શકો છો; કોઈ આદેશની પરવાનગી વિશે ખાતરી ન હોય તો ના કહો, તે ચકાસણી "જોઈ શકાઈ નહીં" તરીકે નોંધાશે.

## તમારી ફાઇલનું શું થાય છે

- **જો તમે "તપાસાવો" કહો, તો તમારી ફાઇલ બદલાતી નથી.** ટીમોને ફક્ત પોતાના `takim` ફોલ્ડરમાં અહેવાલ અને નોંધપોથી લખવાનું કહેવાય છે ("ફક્ત તપાસ"); છતાં તમારી ફાઇલની એક નકલ `takim\yedek\` ફોલ્ડરમાં લેવાય છે.
- **જો તમે "સુધારે" કહો,** તો Claude પહેલાં તમારી ફાઇલની નકલ `takim\yedek\` ફોલ્ડરમાં લે છે અને તમને કહે છે "તમારી ફાઇલ બદલાશે, બેકઅપ અહીં છે". તમારી ફાઇલમાં ફક્ત વાદળી ટીમ લખે છે.
- જો તમારી વિનંતી અસ્પષ્ટ હોય, તો Claude તમારી ફાઇલને અડકતું નથી.
- Word અથવા PDF ફાઇલો ટીમો વાંચી શકે છે કે નહીં તેની પુષ્ટિ થઈ નથી; Claude આ શરૂઆતમાં જ કહે છે અને લખાણમાં રૂપાંતરિત નકલ પર કામ કરે છે.

## ક્યારે પૂરું થાય છે

જો તમે "તપાસાવો" કહ્યું હોય, તો એક તપાસ રાઉન્ડ પછી પૂરું થાય છે: Claude જે મળ્યું તે સમજાવે છે અને સુધારવું કે નહીં તે પૂછે છે. જો તમે "સુધારે" કહ્યું હોય, તો મળેલી ભૂલો સુધારાઈ જાય, સુધારો ફરીથી ચકાસાઈ જાય અને અધૂરી રહેલી દરેક બાબત કેવી રીતે બંધ થશે તે લખાઈ જાય ત્યારે પૂરું થાય છે. તે પૂરું થયા પહેલાં પણ અટકી શકે છે (ઉદાહરણ તરીકે, રાઉન્ડની મહત્તમ સંખ્યા, "રાઉન્ડ મર્યાદા", પર પહોંચે ત્યારે અથવા તમારે નિર્ણય લેવો પડે એવું કંઈક સામે આવે ત્યારે); અટકે ત્યારે Claude કારણ સમજાવે છે અને પૂછે છે. અટકવાની સ્થિતિઓની યાદી નિયમોના 8મા વિભાગમાં છે.

એક રાઉન્ડ કેટલો સમય લે છે તે માપવામાં આવ્યું નથી; ટીમોની સંખ્યા વધે તેમ સમય અને વપરાશ વધે છે.

## કદ અને મોડ

**કદ** એટલે કેટલી ટીમો કામ કરશે. તમે ન કહો તો Claude કામના કદ મુજબ પસંદ કરે છે અને જણાવે છે.

| કદ | ટીમો | રાઉન્ડ મર્યાદા | શેના માટે |
|---|---|---|---|
| ઝડપી | વાદળી, લાલ, ગુલાબી | 2 | નાનું કામ, એક ફાઇલ, ઝડપી ચકાસણી |
| સામાન્ય | + લીલી, રાખોડી, નારંગી | 5 | મોટાભાગનાં કામ |
| પૂર્ણ | + જાંબલી, પીળી, કાળી, સફેદ | 10 | નિર્ણાયક, લાંબા ગાળાનું અથવા પાછું ફેરવવું મોંઘું પડે એવું કામ |

કદમાં એક-એક ટીમ ઉમેરી શકાય છે ("ઝડપી કદ, પીળી ટીમ પણ ઉમેરો"); ગૃહકાર્ય અને લેખનમાં Claude આપમેળે પીળી ટીમ ઉમેરે છે, અને ચલાવવાની જરૂર હોય એવા કામમાં નારંગી ટીમ, અને તે જણાવે છે. રાઉન્ડ મર્યાદાઓ ચકાસાયેલ ન હોય એવાં શરૂઆતનાં મૂલ્યો છે; બદલવા માટે તમારે ફક્ત કહેવું પૂરતું છે.

**મોડ** એટલે શું જોવાશે: **વ્યાપક** (આખું કામ) અથવા **કેન્દ્રિત** (એક જ પ્રશ્ન). તમે એક જ પ્રશ્ન પૂછો તો Claude કેન્દ્રિત મોડ પસંદ કરે છે.

## પરિણામ ક્યાં છે

- Claude પરિણામ તમને વાતચીતમાં સમજાવે છે: સૌથી ઉપર એક વાક્ય, તેની નીચે ટૂંકો સાર; શું **પુરાવાયુક્ત** છે અને શું *અનુમાન* છે તે અલગથી કહેવાય છે; કોઈ પ્રશ્ન હોય તો તે સૌથી નીચે રહે છે.
- તમે જ્યાં કામ કરો છો તે ફોલ્ડરમાં એક `takim` ફોલ્ડર બને છે. આ ટીમોની પોતાની નોંધપોથી છે; તમારે તે વાંચવાની જરૂર નથી. તમારી ફાઇલનું મૂળ સ્વરૂપ પણ આ ફોલ્ડરમાં છે (`takim\yedek\`); સુધારાઓથી સંતુષ્ટ હો તો કામ પૂરું થયા પછી તેને કાઢી શકો છો.
- ટીમોને નોંધ કે અહેવાલ આપવા માટે તમે ફાઇલ `takim\gelen\` ફોલ્ડરમાં મૂકી શકો છો.
- એ જ ફોલ્ડરમાં નવું કામ શરૂ કરો તો જૂના રેકોર્ડ કાઢી નાખાતા નથી; તે `takim\arsiv\` હેઠળ ખસેડાય છે.

નિયમોનું પૂરું લખાણ: `skills/takim-dongu/sablonlar/kurallar.md`.

## અનઇન્સ્ટોલ

- જો તમે `kur.cmd` વડે ઇન્સ્ટોલ કર્યું હોય: `kaldir.cmd` ફાઇલ પર ડબલ-ક્લિક કરો. તે ફક્ત પેકેજની એજન્ટ ફાઇલો અને ત્રણ કૌશલ્ય ફોલ્ડરો કાઢે છે; તમારા પ્રોજેક્ટોમાંના `takim` ફોલ્ડરોને અડકતું નથી. જો કોઈ ફાઇલ કાઢી ન શકાય તો તે સ્ક્રીન પર જણાવે છે.
- જો તમે પ્લગઇન તરીકે ઇન્સ્ટોલ કર્યું હોય: Claude Codeમાં `/plugin` લખો અને ખૂલતી વિન્ડોમાંથી પ્લગઇન દૂર કરો (આ પગલાની પુષ્ટિ થઈ નથી).
- જો તમે એક જ પ્રોજેક્ટમાં નકલ કરી હોય: નકલ કરેલી ફાઇલો તે પ્રોજેક્ટના `.claude` ફોલ્ડરમાંથી કાઢી નાખો.

## અન્ય ઇન્સ્ટોલ પદ્ધતિઓ (અદ્યતન)

ફક્ત એક જ વાપરો. જો તમે `kur.cmd` સાથે પ્લગઇન પદ્ધતિ પણ વાપરો, તો ટીમો યાદીમાં બે વાર દેખાશે.

**પ્લગઇન તરીકે.** નીચે જ્યાં `<takim-ajan klasörünün yolu>` લખ્યું છે ત્યાં તમારા કમ્પ્યુટર પરના આ ફોલ્ડરનો પૂરો પાથ મૂકો. Claude Codeમાં:

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

બીજો આદેશ ઇન્સ્ટોલેશન આપમેળે પૂરું કરતો નથી: તે એક વિન્ડો ખોલે છે; ત્યાં તમે વપરાશકર્તા વ્યાપ (user scope) પસંદ કરો છો. આ આદેશમાં Windows પાથ યોગ્ય રીતે વંચાય છે કે નહીં તેની પુષ્ટિ થઈ નથી. પ્લગઇન તરીકે ઇન્સ્ટોલ થતાં એજન્ટ અને કૌશલ્યનાં નામોની આગળ `takim-ajan:` લાગે છે.

**એક જ પ્રોજેક્ટમાં.** `agents` ફોલ્ડરની અંદરની સામગ્રી પ્રોજેક્ટના `.claude\agents` ફોલ્ડરમાં, અને `skills` ફોલ્ડરની અંદરના ત્રણ ફોલ્ડર પ્રોજેક્ટના `.claude\skills` ફોલ્ડરમાં નકલ કરો. ત્રણેય કૌશલ્ય ફોલ્ડર સાથે જ નકલ કરવા જોઈએ.
