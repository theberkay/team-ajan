# Team Ajan

## 何に役立つか

あなたの作業(コード、工学計算、建築プロジェクト、製品/UI デザイン、課題、調査、文章、計画)を一人の目ではなく、互いにチェックし合う別々の「チーム」に検査させます。希望すれば、誤りがなくなるまで修正させることもできます。Claude Code 用のプラグインパッケージです。中には 2 種類のファイルがあります:**エージェント**(チームがどう動くかを記した指示)と **スキル**(Claude がチームをどう管理するかを記した指示)。

## インストール

1. パッケージを圧縮ファイル(zip)で受け取った場合は、まずフォルダーに展開してください。
2. `kur.cmd` ファイルをダブルクリックします。画面に「Kuruldu」と表示されるのを確認してください。
3. Claude を閉じて、もう一度開きます。

`kur.cmd` はエージェントファイルと 3 つのスキルフォルダーだけを Claude のユーザーフォルダー(`%USERPROFILE%\.claude`)にコピーします。同じ名前の古いものは上書きされるため、その 3 つのフォルダーにその名前で自分のファイルを置かないでください。コピー先フォルダーは画面に表示されます。新しいバージョンが出たら、同じファイルをもう一度実行するだけで十分です。その他のインストール方法は一番下にあります。

## インストール後の最初のひとこと

検査したいファイルがあるフォルダーで Claude を開き、次のいずれかを入力してください。文中に **「チーム」** という言葉が含まれている必要があります。含まれていないとチームは動きません。

| したいこと | 入力する文 |
|---|---|
| 検査だけして、ファイルには触れないでほしい | `rapor.md をチームに検査させて、手は加えないで` |
| 検査して修正してほしい | `hesap.md をチームが誤りがなくなるまで修正して` |
| ひとつの質問に集中してほしい | `チームはこれだけを見て:このテストはなぜときどき失敗する?` |
| ひとつのチームの意見 | `レッドチームはこの課題を攻撃して` · `イエローチームの目で見て` · `ターコイズチームは無駄を見て` |
| 手元のメモも考慮してほしい | `これをチームにメモとして渡して:…` |
| どこまで進んだか | `チームの状況は?` |
| 中断したところから続ける · 止める | `チームは続けて` · `チームを止めて` |

スキルのトリガーはトルコ語で書かれています。「takım」/「takımlar」(チーム)という語を含む依頼は確実にトリガーされます。他の言語での依頼も動作する可能性はありますが、検証されていません。

Claude はまず短い要約(何を理解したか、何を仮定したか、いくつのチームが最大何ラウンド動くか)を示してから始めます。作業中、ファイルの書き込みやコマンドの実行の許可を求めることがあります。何回求めるかはまだ測定されていません。`takim` フォルダーへの書き込み許可には「はい」と答えて構いません。コマンドの許可に確信が持てなければ「いいえ」と答えてください。その検証は「確認できなかった」と報告されます。

## ファイルはどうなるか

- **「検査させて」と言えば、ファイルは変更されません。** チームには自分の `takim` フォルダーにだけレポートと記録を書くよう指示されます(「検査のみ」)。それでもファイルのコピーは `takim\yedek\` フォルダーに取られます。
- **「修正して」と言えば、** Claude はまずファイルのコピーを `takim\yedek\` フォルダーに取り、「ファイルが変更されます。バックアップはここにあります」と伝えます。ファイルに書き込むのはブルーチームだけです。
- 依頼があいまいな場合、Claude はファイルに触れません。
- Word や PDF ファイルをチームが読めることは検証されていません。Claude は最初にそれを伝え、テキストに変換したコピーで作業します。

## いつ終わるか

「検査させて」と言った場合は、1 回の検査ラウンドの後に終わります。Claude は見つけたことを説明し、修正するかどうかを尋ねます。「修正して」と言った場合は、見つかった誤りが修正され、修正されたことが再検証され、未完了のものすべてについてどう閉じるかが書かれたときに終わります。終わる前に止まることもあります(たとえば最大ラウンド数、つまり「ラウンド上限」に達したとき、あるいはあなたが決める必要のあることが出てきたとき)。止まったときは、Claude が理由を説明して尋ねます。停止条件の一覧はルールの第 8 節にあります。

1 ラウンドにかかる時間は測定されていません。チーム数が増えるほど時間と使用量は増えます。

「成果物」とは、検査対象のファイルや作業のことです。Claude の画面はチーム用に 8 色しか認識しません。そのためグレーはシアンに見え、ブラックとホワイトには色がありません。チームは名前で見分けてください。

## 規模とモード

**規模**とは、いくつのチームが動くかです。指定しなければ、Claude が作業の大きさに応じて選び、知らせます。

| 規模 | チーム | ラウンド上限 | 用途 |
|---|---|---|---|
| 高速 | ブルー、レッド、ピンク | 2 | 小さな作業、単一ファイル、素早いチェック |
| 標準 | + グリーン、グレー、オレンジ | 5 | ほとんどの作業 |
| 完全 | + パープル、イエロー、ブラック、ホワイト | 10 | 重要、長く使われる、または元に戻すのが高くつく作業 |

規模にはチームを個別に追加できます(「高速規模で、イエローチームも追加して」)。課題や文章ではイエローを、実行が必要な作業ではオレンジを Claude が自動で追加し、そのことを伝えます。ラウンド上限は検証されていない初期値です。変更したければ伝えるだけで十分です。

**モード**とは、何を見るかです:**広域**(作業全体)または **焦点**(ひとつの質問)。ひとつの質問をすれば、Claude は焦点モードを選びます。

## 結果はどこにあるか

- 結果は Claude がチャットで説明します:一番上に一文、その下に短い要約。何が**証拠あり**で何が*推測*かは分けて述べられます。質問があれば一番下にあります。
- 作業中のフォルダーに `takim` フォルダーが作られます。これはチーム自身の記録で、読む必要はありません。ファイルの元の状態もこのフォルダーにあります(`takim\yedek\`)。修正に満足していれば、作業完了後に削除して構いません。
- チームにメモやレポートを渡すには、ファイルを `takim\gelen\` フォルダーに置くことができます。
- 同じフォルダーで新しい作業を始めても古い記録は削除されず、`takim\arsiv\` の下に移動されます。

ルールの全文:`skills/takim-dongu/sablonlar/kurallar.md`。

## アンインストール

- `kur.cmd` でインストールした場合:`kaldir.cmd` ファイルをダブルクリックします。パッケージのエージェントファイルと 3 つのスキルフォルダーだけを削除し、プロジェクト内の `takim` フォルダーには触れません。削除できないファイルが残った場合は、画面でそれを伝えます。
- プラグインとしてインストールした場合:Claude Code で `/plugin` と入力し、開いたウィンドウからプラグインを削除します(この手順は検証されていません)。
- 単一のプロジェクトにコピーした場合:コピーしたファイルをそのプロジェクトの `.claude` フォルダーから削除します。

## その他のインストール方法(上級者向け)

どれかひとつだけを使ってください。`kur.cmd` と一緒にプラグイン方式も使うと、チームが一覧に 2 回表示されます。

**プラグインとして。** 下の `<takim-ajan klasörünün yolu>` と書かれた箇所に、このフォルダーのコンピューター上のフルパスを入れてください。Claude Code で:

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

2 つ目のコマンドはインストールを自動では完了しません。ウィンドウが開き、そこでユーザースコープを選びます。このコマンドで Windows のパスが正しく読み取られることは検証されていません。プラグインとしてインストールすると、エージェント名とスキル名の先頭に `takim-ajan:` が付きます。

**単一のプロジェクトに。** `agents` フォルダーの中身をプロジェクトの `.claude\agents` フォルダーに、`skills` フォルダー内の 3 つのフォルダーをプロジェクトの `.claude\skills` フォルダーにコピーします。3 つのスキルフォルダーは一緒にコピーする必要があります。
