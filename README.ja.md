# Team Ajan

🌐 [Türkçe](README.md) · [English](README.en.md) · [All languages](LANGUAGES.md)

## 何ができるか

あなたの仕事（コード、工学計算、建築プロジェクト、製品／インターフェース設計、課題、調査、文章、計画）を、ひとつの目ではなく、互いをチェックし合う別々の「チーム」にレビューさせます。希望すれば、誤りがなくなるまで修正させます。Claude Code 用のプラグインパッケージです。中には 2 種類のファイルがあります：**エージェント**（チームがどう動くかを記した指示）と **スキル**（Claude がチームをどう取りまとめるかを記した指示）。

分野ガイド（`skills/takim-dongu/sablonlar/alanlar.md`）は、次の分野でチームが何を見るべきかを示します：コード、エンジニアリング、機械、メカトロニクス、電気、重工業、建築、設計とデザイン、単元の解説と課題、プレゼンテーション、調査、文書化、医学、法律、政治、歴史、音楽。医学と法律では、チームは診断・治療・法的見解を示しません。本文とその出典だけをレビューし、結果には「専門家に相談してください」という注記が付きます。

## インストール

1. パッケージを圧縮ファイル（zip）で受け取った場合は、まずフォルダーに展開してください。
2. `kur.cmd` をダブルクリックします。画面に「Kuruldu」（インストール完了）と表示されます。
3. Claude を閉じて、もう一度開きます。

`kur.cmd` はエージェントファイルと 3 つのスキルフォルダーだけを Claude のユーザーフォルダー（`%USERPROFILE%\.claude`）にコピーします。同じ名前の古いものは上書きするので、その 3 つのフォルダーやその名前で自分のファイルを置かないでください。コピー先フォルダーは画面に表示されます。新しいバージョンが出たら、同じファイルをもう一度実行するだけです。他のインストール方法は一番下にあります。

## インストール後の最初のひとこと

レビューしたいファイルがあるフォルダーで Claude を開き、次のいずれかを入力します。文には **「takım」**（チーム）という語が含まれている必要があります。含まれていないとチームは動きません。

| したいこと | 入力する文 |
|---|---|
| レビューだけ、ファイルには触れない | `rapor.md をチームにレビューさせて、触らないで` |
| レビューして修正 | `hesap.md を誤りがなくなるまでチームに修正させて` |
| ひとつの問いに集中 | `チームはこれだけ見て：このテストはなぜ時々失敗する？` |
| ひとつのチームの意見 | `赤チーム、この課題を攻撃して` · `黄チームの目で見て` · `ターコイズチーム、無駄を探して` |
| 自分のメモも考慮させる | `これをチームにメモとして渡して：…` |
| どこまで進んだか | `チームはどうなってる？` |
| 中断したところから続ける · 止める | `チーム、続けて` · `チームを止めて` |

スキルのトリガーはトルコ語で書かれています。「takım」／「takımlar」を含む依頼では確実に起動しますが、他の言語での依頼は動く可能性はあるものの、テストされていません。

Claude はまず短い要約（何を理解したか、何を仮定したか、何チームが最大何ラウンド動くか）を示してから始めます。作業中、ファイルの書き込みやコマンド実行の許可を求めることがあります。何回求めるかはまだ測定されていません。`takim` フォルダーへの書き込み許可には「はい」と答えて構いません。コマンドの許可に確信が持てない場合は「いいえ」と答えてください。そのチェックは「確認できなかった」と報告されます。

## あなたのファイルはどうなるか

- **「レビュー」と言えば、ファイルは変わりません。** チームには自分たちの `takim` フォルダーにだけレポートと記録を書くよう指示されます（「レビューのみ」）。それでもファイルのコピーは `takim\yedek\` フォルダーに保存されます。
- **「修正」と言えば、** Claude はまずファイルのコピーを `takim\yedek\` フォルダーに保存し、「ファイルが変更されます。バックアップはここです」と伝えます。あなたのファイルに書き込むのは青チームだけです。
- 依頼があいまいな場合、Claude はファイルに触れません。
- チームが Word や PDF ファイルを読めることは検証されていません。Claude は最初にそのことを伝え、テキストに変換したコピーで作業します。

## いつ終わるか

「レビュー」と言った場合は、1 回のレビューラウンドで終わります：Claude が見つけたことを説明し、修正するかどうか尋ねます。「修正」と言った場合は、見つかった誤りが修正され、その修正が再確認され、やり残したすべての事柄をどう片付けるかが書き出された時点で終わります。終わる前に止まることもあります（たとえば最大ラウンド数、つまり「ラウンド上限」に達したとき、あなたが決めるべきことが出てきたとき）。止まったときは Claude が理由を説明して尋ねます。停止条件の一覧はルールの第 8 節にあります。

1 ラウンドにかかる時間は測定されていません。チーム数が増えるほど時間と使用量が増えます。

「成果物」とは、レビュー対象のあなたのファイルや仕事のことです。Claude の画面はチーム用に 8 色しか認識しません。そのためグレーはシアンで表示され、黒と白には色がありません。チームは名前で見分けてください。

## 規模とモード

**規模** とは、何チームが動くかです。指定しなければ、Claude が仕事の大きさに応じて選び、知らせます。

| 規模 | チーム | ラウンド上限 | 用途 |
|---|---|---|---|
| クイック | 青、赤、ピンク | 2 | 小さな仕事、単一ファイル、手早い確認 |
| ノーマル | ＋ 緑、グレー、オレンジ | 5 | ほとんどの仕事 |
| フル | ＋ 紫、黄、黒、白 | 10 | 重要、長く使う、または元に戻すのが高くつく仕事 |

規模にはチームを 1 つずつ追加できます（「クイック規模で、黄チームも追加して」）。課題や文章では Claude が自分から黄を、実行が必要な仕事ではオレンジを追加し、そのことを伝えます。ラウンド上限はテストされていない初期値です。変えたいときは伝えるだけで構いません。

**モード** とは何を見るかです：**ワイド**（仕事全体）または **フォーカス**（ひとつの問い）。ひとつの問いを尋ねると、Claude はフォーカスモードを選びます。

## 結果はどこにあるか

- 結果は Claude がチャットで伝えます：一番上に一文、その下に短い要約。何が **証明済み** で何が *推定* かは分けて述べられます。質問があれば一番下にあります。
- 作業しているフォルダーに `takim` フォルダーが作られます。これはチーム自身の記録で、読む必要はありません。ファイルの元の状態もこのフォルダー（`takim\yedek\`）にあります。修正に満足したら、作業終了後に削除して構いません。
- チームにメモやレポートを渡すには、ファイルを `takim\gelen\` フォルダーに置きます。
- 同じフォルダーで新しい仕事を始めても、古い記録は削除されず、`takim\arsiv\` の下に移されます。

ルールの全文：`skills/takim-dongu/sablonlar/kurallar.md`。

## アンインストール

- `kur.cmd` でインストールした場合：`kaldir.cmd` をダブルクリックします。パッケージのエージェントファイルと 3 つのスキルフォルダーだけを削除し、プロジェクト内の `takim` フォルダーには触れません。削除できなかったファイルが残った場合は、画面にそう表示します。
- プラグインとしてインストールした場合：Claude Code で `/plugin` と入力し、開いたウィンドウからプラグインを削除します（この手順は検証されていません）。
- 単一のプロジェクトにコピーした場合：コピーしたファイルをそのプロジェクトの `.claude` フォルダーから削除します。

## その他のインストール方法（上級者向け）

どれかひとつだけを使ってください。`kur.cmd` と併せてプラグインの方法も使うと、チームが一覧に 2 回表示されます。

**プラグインとして。** 下の `<takim-ajan klasörünün yolu>` の部分に、このフォルダーのコンピューター上の完全なパスを入れてください。Claude Code で：

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

2 つ目のコマンドだけではインストールは完了しません：ウィンドウが開くので、そこでユーザースコープを選びます。このコマンドで Windows のパスが正しく読まれることは検証されていません。プラグインとしてインストールすると、エージェント名とスキル名の先頭に `takim-ajan:` が付きます。

**単一のプロジェクトに。** `agents` フォルダーの中身をプロジェクトの `.claude\agents` フォルダーに、`skills` フォルダー内の 3 つのフォルダーをプロジェクトの `.claude\skills` フォルダーにコピーします。3 つのスキルフォルダーは一緒にコピーする必要があります。
