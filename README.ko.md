# Team Ajan

🌐 [Türkçe](README.md) · [English](README.en.md) · [All languages](LANGUAGES.md)

## 무엇에 쓰나요

여러분의 작업(코드, 공학 계산, 건축 설계, 제품 / 인터페이스 디자인, 과제, 연구, 글, 계획)을 한 사람의 눈이 아니라 서로를 감시하는 여러 "팀"이 검토하게 하고, 원하면 오류가 하나도 남지 않을 때까지 고치게 합니다. Claude Code용 플러그인 패키지입니다. 안에는 두 종류의 파일이 있습니다: **에이전트**(한 팀이 어떻게 일할지 설명하는 지침)와 **스킬**(Claude가 팀들을 어떻게 운영할지 설명하는 지침).

## 설치

1. 패키지를 압축 파일(zip)로 받았다면 먼저 폴더에 압축을 풉니다.
2. `kur.cmd` 파일을 더블클릭합니다. 화면에 "Kuruldu"가 표시되는지 확인합니다.
3. Claude를 닫았다가 다시 엽니다.

`kur.cmd`는 에이전트 파일과 스킬 폴더 세 개만 Claude 사용자 폴더(`%USERPROFILE%\.claude`)에 복사합니다. 같은 이름의 기존 파일을 덮어쓰므로, 그 세 폴더에 그 이름으로 직접 만든 파일을 두지 마세요. 대상 폴더는 화면에 표시됩니다. 새 버전이 나오면 같은 파일을 다시 실행하면 됩니다. 다른 설치 방법은 맨 아래에 있습니다.

## 설치 후 첫 문장

검토할 파일이 있는 폴더에서 Claude를 열고 다음 중 하나를 입력하세요. 문장에 **"팀"**이라는 말이 들어가야 하며, 없으면 팀들이 작동하지 않습니다.

| 원하는 것 | 입력할 문장 |
|---|---|
| 검토만 하고 내 파일은 건드리지 않기 | `rapor.md 파일을 팀들에게 검토시켜, 건드리지는 말고` |
| 검토하고 고치기 | `팀들이 hesap.md 파일을 오류가 없어질 때까지 고쳐 줘` |
| 질문 하나에 집중하기 | `팀들은 이것만 봐 줘: 이 테스트는 왜 가끔 실패하지?` |
| 한 팀의 의견 | `빨강 팀이 이 과제를 공격해 줘` · `노랑 팀의 눈으로 봐 줘` · `청록 팀이 낭비를 살펴봐 줘` |
| 내 메모도 고려하기 | `이걸 팀들에게 메모로 전달해 줘: …` |
| 어디까지 했는지 | `팀들 상황은 어때?` |
| 멈춘 곳부터 계속 · 멈추기 | `팀들 계속해 줘` · `팀들 멈춰` |

> 스킬 트리거는 튀르키예어로 작성되어 있습니다. "takım" / "takımlar"라는 말이 들어간 요청은 안정적으로 트리거되며, 다른 언어의 요청은 작동할 수도 있지만 검증되지 않았습니다.

Claude는 먼저 짧은 요약(무엇을 이해했는지, 무엇을 가정했는지, 몇 개 팀이 최대 몇 라운드 일할지)을 알려 준 뒤 시작합니다. 작업 중에 파일 쓰기와 명령 실행을 위한 허락을 구할 수 있으며, 몇 번이나 묻는지는 아직 측정되지 않았습니다. `takim` 폴더에 쓰는 허락에는 예라고 해도 됩니다. 어떤 명령의 허락이 확실하지 않으면 아니요라고 하세요. 그 검증은 "확인하지 못함"으로 보고됩니다.

## 내 파일은 어떻게 되나요

- **"검토"라고 하면 파일이 바뀌지 않습니다.** 팀들은 자기 `takim` 폴더에만 보고서와 기록을 쓰라는 지시를 받습니다("검토만"). 그래도 파일의 사본은 `takim\yedek\` 폴더에 보관됩니다.
- **"고쳐"라고 하면** Claude가 먼저 파일의 사본을 `takim\yedek\` 폴더에 보관하고 "파일이 바뀝니다, 백업은 여기 있습니다"라고 알려 줍니다. 파일에는 파랑 팀만 씁니다.
- 요청이 모호하면 Claude는 파일을 건드리지 않습니다.
- 팀들이 Word나 PDF 파일을 읽을 수 있는지는 확인되지 않았습니다. Claude는 처음에 이 점을 말하고 텍스트로 변환한 사본으로 작업합니다.

## 언제 끝나나요

"검토"라고 했다면 검토 라운드 한 번 뒤에 끝납니다. Claude가 찾은 것을 설명하고 고칠지 묻습니다. "고쳐"라고 했다면 찾은 오류가 고쳐지고, 고쳐졌는지 다시 검증되고, 미완성으로 남은 모든 것을 어떻게 마무리할지 적혔을 때 끝납니다. 끝나기 전에 멈출 수도 있습니다(예: 최대 라운드 수인 "라운드 상한"에 이르렀거나 여러분이 결정해야 할 일이 생겼을 때). 멈추면 Claude가 이유를 설명하고 묻습니다. 멈추는 경우의 목록은 규칙의 8장에 있습니다.

한 라운드에 걸리는 시간은 측정되지 않았습니다. 팀 수가 늘수록 시간과 사용량이 늘어납니다.

"작품"은 검토 중인 여러분의 파일이나 작업입니다. Claude 화면은 팀에 대해 여덟 가지 색만 인식하므로 회색은 청록색(시안)으로 보이고, 검정과 흰색은 색이 없습니다. 팀은 이름으로 구별하세요.

## 규모와 모드

**규모**는 몇 개 팀이 일할지입니다. 말하지 않으면 Claude가 작업 크기에 맞춰 고르고 알려 줍니다.

| 규모 | 팀 | 라운드 상한 | 용도 |
|---|---|---|---|
| 빠름 | 파랑, 빨강, 분홍 | 2 | 작은 일, 파일 하나, 빠른 점검 |
| 보통 | + 초록, 회색, 주황 | 5 | 대부분의 일 |
| 전체 | + 보라, 노랑, 검정, 흰색 | 10 | 중요하거나, 오래 쓰이거나, 되돌리기 비싼 일 |

규모에 팀을 하나씩 추가할 수 있습니다("빠른 규모로, 노랑 팀도 추가해 줘"). 과제와 글에는 노랑을, 실행이 필요한 일에는 주황을 Claude가 스스로 추가하고 알려 줍니다. 라운드 상한은 검증되지 않은 초기값이며, 바꾸려면 말만 하면 됩니다.

**모드**는 무엇을 볼지입니다: **넓게**(작업 전체) 또는 **집중**(질문 하나). 질문 하나를 하면 Claude는 집중 모드를 고릅니다.

## 결과는 어디에

- Claude가 대화창에서 결과를 알려 줍니다. 맨 위에 한 문장, 그 아래 짧은 요약이 있고, 무엇이 **입증된** 것이고 무엇이 *추정*인지 따로 말합니다. 질문이 있으면 맨 아래에 있습니다.
- 작업 중인 폴더에 `takim` 폴더가 만들어집니다. 이것은 팀들의 자체 기록장이며 읽을 필요는 없습니다. 파일의 원래 상태도 이 폴더(`takim\yedek\`)에 있습니다. 수정 결과에 만족하면 작업이 끝난 뒤 지워도 됩니다.
- 팀들에게 메모나 보고서를 주려면 파일을 `takim\gelen\` 폴더에 넣으면 됩니다.
- 같은 폴더에서 새 작업을 시작해도 이전 기록은 지워지지 않고 `takim\arsiv\` 아래로 옮겨집니다.

규칙 전문: `skills/takim-dongu/sablonlar/kurallar.md`.

## 제거

- `kur.cmd`로 설치했다면: `kaldir.cmd` 파일을 더블클릭하세요. 패키지의 에이전트 파일과 스킬 폴더 세 개만 지우며, 프로젝트의 `takim` 폴더는 건드리지 않습니다. 지우지 못한 파일이 남으면 화면에 알려 줍니다.
- 플러그인으로 설치했다면: Claude Code에서 `/plugin`을 입력하고 열리는 창에서 플러그인을 제거하세요(이 단계는 확인되지 않았습니다).
- 한 프로젝트에 복사했다면: 복사한 파일을 그 프로젝트의 `.claude` 폴더에서 지우세요.

## 다른 설치 방법(고급)

하나만 사용하세요. `kur.cmd`와 플러그인 방법을 함께 쓰면 팀이 목록에 두 번 나타납니다.

**플러그인으로.** 아래 `<takim-ajan klasörünün yolu>`라고 적힌 자리에 컴퓨터에서 이 폴더의 전체 경로를 넣으세요. Claude Code에서:

```
/plugin marketplace add <takim-ajan klasörünün yolu>
/plugin install takim-ajan@takim-ajan-yerel
```

두 번째 명령은 설치를 저절로 끝내지 않습니다. 창이 열리고, 거기서 사용자 범위를 선택합니다. 이 명령에서 Windows 경로가 제대로 읽히는지는 확인되지 않았습니다. 플러그인으로 설치하면 에이전트와 스킬 이름 앞에 `takim-ajan:`이 붙습니다.

**한 프로젝트에.** `agents` 폴더의 내용을 프로젝트의 `.claude\agents` 폴더에, `skills` 폴더 안의 세 폴더를 프로젝트의 `.claude\skills` 폴더에 복사하세요. 스킬 폴더 세 개는 함께 복사해야 합니다.
